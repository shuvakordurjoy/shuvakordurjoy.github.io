## 🔒 How the CV & Project Report Request-and-Approval System Works

1. **Visitor Requests Access**: When any visitor clicks **Download CV**, **Read Attached Project Report PDF**, or **Download Full Report**, an **Access Request Modal** opens instead of downloading immediately.
2. **Email Sent to Your Gmail (`shuvakordurjoy2002@gmail.com`)**: The visitor fills in their Name, Email, Organization, Requested Document, and Purpose, which sends an email to `shuvakordurjoy2002@gmail.com`.
3. **How You Approve a Request**: Inside the email you receive, you will see the visitor's **Personal Approval Code** (e.g. `DJ-XXX-XXX`) and a **One-Click Unlock Link** (`https://durjoybhowmikportfolio.netlify.app/?approve_email=...&approve_code=...`).
   - Simply click **Reply** in Gmail and send that Approval Code or One-Click Unlock Link to the visitor!
   - Once they click the link (or enter the code in Tab 2: *"I Have an Approval Code"*), their browser unlocks the CV and Project Report PDF for download.
   - *(Note for Owner: Your master override code is `DURJOY-APPROVE-2026`)*
